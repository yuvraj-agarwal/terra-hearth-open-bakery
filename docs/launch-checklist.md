# Launch Checklist — Terra Hearth Style Organic Bakery

Use this sequential checklist. Do not skip steps.

## Phase 0 — Foundation (Weeks 1–4)

- [ ] Decide legal entity (sole prop / LLP / Pvt Ltd)
- [ ] Register for GST if required
- [ ] Apply for FSSAI licence
- [ ] Research and shortlist 2–3 APEDA-accredited NPOP certification bodies
- [ ] Identify potential organic grain suppliers / mills / FPOs
- [ ] Create basic brand name, domain, and simple visual identity
- [ ] Draft initial 6–8 SKU product list

## Phase 1 — Certification & Supply (Weeks 3–12)

- [ ] Submit NPOP application and Organic System Plan
- [ ] Complete facility requirements for organic processing
- [ ] Secure first organic flour and ingredient contracts
- [ ] Finalise recipes and cost them accurately
- [ ] Source compostable packaging
- [ ] Set up basic accounting and inventory tracking

## Phase 2 — Kitchen & Production Readiness (Weeks 8–14)

- [ ] Secure cloud / micro kitchen space
- [ ] Install equipment (ovens, mixers, proofers, stone mill if planned)
- [ ] Hire / train first baker(s) in long fermentation methods
- [ ] Run test batches and shelf-life tests
- [ ] Establish zero-waste processes
- [ ] Obtain final NPOP scope certificate and FSSAI licence

## Phase 3 — Soft Launch (Weeks 12–20)

- [ ] Build simple ordering website or WhatsApp + form system
- [ ] Set up delivery logistics (own + selective aggregators)
- [ ] Create subscription waitlist / Bread Club
- [ ] Soft launch to friends, family, and local health communities
- [ ] Collect feedback and refine recipes / packaging
- [ ] Start basic content (fermentation, millets, farm stories)

## Phase 4 — Public Launch & Early Traction

- [ ] Open public ordering
- [ ] Launch first subscription cycle
- [ ] Approach 3–5 local organic stores / cafés for B2B trials
- [ ] Track unit economics weekly
- [ ] Iterate product mix based on real sales data
- [ ] Keep waste under 3%

## Ongoing (Never Stop)

- [ ] Weekly review of food cost %, waste %, and contribution margins
- [ ] Maintain certification and audit readiness
- [ ] Build direct customer relationships and email/WhatsApp list
- [ ] Only expand SKUs or channels when current ones are profitable

---

**Golden Rule**: Do not open a customer-facing café or invest heavily in retail until cloud + subscription unit economics are clearly positive.
