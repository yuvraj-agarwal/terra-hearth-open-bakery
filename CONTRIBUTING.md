# Contributing to Terra Hearth Open Bakery

Thank you for helping improve this open-source bakery playbook.

## Ways to Contribute

- Improve documentation clarity or structure
- Add real-world cost data from different Indian cities or other countries
- Expand the product matrix with tested recipes and costings
- Share supplier recommendations (NPOP-certified mills, millet farmers, packaging)
- Add templates (financial models, marketing calendars, SOPs)
- Translate key sections into other languages
- Report outdated regulatory information (FSSAI / NPOP changes)
- Share case studies of bakeries that adapted this model

## How to Contribute

1. Fork the repository
2. Create a clear branch name (`docs/improve-certification-guide`, `add/mumbai-cost-data`, etc.)
3. Make focused changes
4. Open a pull request with a short description of what you improved and why

## Guidelines

- Keep the tone practical and founder-friendly
- Prefer real numbers and sources over theory
- Clearly mark regional differences (India vs other markets)
- Do not add promotional content for private brands without disclosure
- Maintain the open, non-hype spirit of the playbook

## Code of Conduct

Be respectful. This project exists to help serious founders build better, more honest bakeries. Gatekeeping, spam, or low-effort content will not be accepted.
